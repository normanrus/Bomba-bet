# БОМБА БЕТ

Закрытый шуточный проект для компании друзей: спортивные прогнозы на
виртуальные очки. Никаких денежных депозитов, платных ставок и азартных игр.
Участие бесплатное, призы администратор выдаёт вручную в Telegram Stars.

## Что внутри

| Каталог              | Что это                                                   |
| -------------------- | --------------------------------------------------------- |
| `backend/`           | REST API: Node.js + TypeScript + PostgreSQL + JWT          |
| `admin/`             | Админ-панель: React + TypeScript + Vite                    |
| `android/`           | Android-приложение: Kotlin + Jetpack Compose               |
| `docker-compose.yml` | Полный стек: база, API, админка, резервное копирование      |
| `docker/`            | Скрипт и каталог резервных копий                           |
| `docs/`              | Инструкции по развёртыванию и сборке APK                   |

Сервер настоящий: данные живут в PostgreSQL, авторизация — на сервере,
клиент не может изменить баланс. Ничего не подменяется localStorage.

## Быстрый старт (Docker)

```bash
cp .env.example .env       # задайте POSTGRES_PASSWORD и JWT_SECRET
docker compose up -d --build
docker compose logs api | grep -A4 "начальный администратор"   # пароль admin
```

* API — http://localhost:4000/api/health
* Админ-панель — http://localhost:8080
* Скачать APK — http://localhost:8080/download/release/app-release.apk

Миграции и создание администратора выполняются автоматически при старте.
Подробности — в `docs/DEPLOYMENT.md`.

### Онлайн-режим

Приложение работает через интернет: наружу достаточно опубликовать один адрес
(контейнер `admin`), потому что его nginx уже проксирует API на том же origin.
Соберите APK с этим публичным адресом:

```bash
cd android
gradle :app:assembleRelease -PapiBaseUrl=https://<ваш-домен>
```

Готовый APK будет доступен по `https://<ваш-домен>/download/release/app-release.apk`.

## Документация

* `docs/DEPLOYMENT.md` — запуск сервера, переменные окружения, бэкапы, обновления.
* `docs/DEPLOY_CLOUD.md` — деплой в облако: Docker-backend на любом хостинге, база Neon, админка на Vercel.
* `docs/DEPLOY_STEP_BY_STEP.md` — подробный туториал по деплою без Render: Northflank + база + Vercel + APK.
* `docs/DEPLOY_TUNNEL.md` — запуск на своём компьютере + публичный адрес через Cloudflare Tunnel (скрипт `scripts/tunnel.sh`).
* `docs/BUILD_APK.md` — установка Android SDK и сборка APK.

## Возможности

* Регистрация и вход по JWT (access + refresh), безопасное хранение паролей (bcrypt).
* Виртуальный баланс очков с неизменяемым журналом (ledger); баланс меняет только сервер.
* Два счётчика очков: бонусные (подарочные) и выводимые (выигранные в прогнозах).
  На приз принимаются только выводимые очки.
* Спортивные события с рынками и вариантами прогнозов; коэффициенты — игровые множители.
* Автоматический расчёт выигрышей при завершении матча; защита от повторной выплаты.
* Приветственный бонус и прозрачный ежедневный случайный бонус (шанс и диапазон открыты).
* Заявки на призы с очередью на стороне администратора; выдача вручную в Telegram Stars.
  Общий призовой фонд — 125 ⭐ (настраивается в админ-панели).
* Таблица лидеров, история прогнозов, статистика побед и поражений.
* Админ-панель: статистика, пользователи, события, призы, настройки, журнал аудита.
* Резервное копирование PostgreSQL по расписанию.

```bash
# backend: сквозной сценарий API (нужен запущенный сервер)
ADMIN_PASSWORD='<пароль>' bash backend/scripts/e2e.sh

cd android && gradle :app:testDebugUnitTest
```

## Безопасность

* Все важные операции выполняются на сервере и проверяют права доступа.
* Пароли хранятся как bcrypt-хэши; первый вход администратора требует смены пароля.
* Защита от повторной выдачи выигрыша и от повторных запросов (idempotency key).
* Ограничение частоты запросов (rate limit) на чувствительных маршрутах.
* Административные действия пишутся в журнал аудита.
