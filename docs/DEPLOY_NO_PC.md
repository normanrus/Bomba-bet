# Запуск БОМБА БЕТ без компьютера (только телефон)

Если под рукой нет ПК, «Вариант А» (сервер на своём компьютере) не подходит —
но его можно повторить в браузере: роль компьютера сыграет бесплатное облако.

Есть три пути. Начните с первого — он работает сразу.

---

## Путь 1. Сервер уже запущен в этом окружении (проверить сейчас)

Это рабочее окружение уже поднимает весь стек. Откройте с телефона:

```
https://work-1-khwzvsgqpdtsovih.prod-runtime.all-hands.dev/
```

- Логин админа: `owner`, пароль скажет агент (он задаёт его при запуске).
- API health: тот же адрес + `/api/health`.
- Скачать APK: тот же адрес + `/download/release/app-release.apk`.

Важно: это окружение живёт, пока открыта эта сессия. Для постоянного сервера —
путь 2 или 3.

---

## Путь 2. GitHub Codespaces — «компьютер в браузере» (бесплатно, без карты)

Codespaces даёт полноценную Linux-машину прямо в браузере. Бесплатный лимит для
личных аккаунтов: **120 часов в месяц**. Карта не нужна.

### Шаг 1. Создать codespace

1. Откройте репозиторий на GitHub: `https://github.com/normanrus/Bomba-bet`
2. Кнопка **Code** (зелёная) → вкладка **Codespaces** → **Create codespace on main**.
3. Подождите 1–2 минуты. Откроется редактор в браузере — это и есть компьютер.

Настройка окружения (`.devcontainer/`) уже в репозитории, поэтому Codespaces сам
поставит Docker, Node и Android SDK.

### Шаг 2. Запустить сервер

В терминале внизу (меню **Terminal → New Terminal**):

```bash
bash scripts/codespace-up.sh
```

Скрипт поднимет базу, API и админку и напечатает адрес вида:

```
https://<имя-codespace>-8080.app.github.dev
```

Это и есть админка + API. Откройте с телефона.

### Шаг 3. Сделать порт публичным

Codespaces обычно делает порт 8080 публичным сам (см. `devcontainer.json`). Если
адрес не открывается:

1. Внизу откройте вкладку **PORTS**.
2. Правый клик по порту **8080** → **Port Visibility** → **Public**.

### Шаг 4. Собрать APK

```bash
bash scripts/build-apk.sh https://<имя-codespace>-8080.app.github.dev
```

Готово. Скачать APK на телефон:

```
https://<имя-codespace>-8080.app.github.dev/download/release/app-release.apk
```

### Ограничения

- Codespace засыпает после 30 минут простоя — это нормально, разбудите кнопкой.
- 120 часов в месяц: хватает для компании друзей, но это не «сервер 24/7».

## Путь 3. Render + Neon — сервер, который работает без вас (бесплатно, без карты)

Это единственный бесплатный путь, где сервер живёт сам, без вашего телефона.

- **Render** — бесплатный веб-сервис (карта не требуется). Минус: засыпает после
  15 минут простоя и просыпается ~30 секунд при первом запросе. Для компании
  друзей это нормально.
- **Neon** — бесплатная PostgreSQL, которая **не истекает** (в отличие от
  бесплатной базы Render, которую удаляют через 30 дней).

Полная пошаговая инструкция — `docs/DEPLOY_STEP_BY_STEP.md`.

Коротко:

1. Регистрация на [neon.tech](https://neon.tech) → создайте проект → скопируйте
   строку подключения (`postgresql://...`).
2. Регистрация на [render.com](https://render.com) → **New → Web Service** →
   подключите репозиторий `normanrus/Bomba-bet`.
3. Настройки сервиса:
   - **Root Directory**: `backend`
   - **Runtime**: Docker (или Node с build `npm ci --include=dev && npm run build`)
   - **Environment variables**:
     - `DATABASE_URL` = строка из Neon
     - `JWT_SECRET` = любая строка из 32+ символов
     - `ADMIN_USERNAME` = `owner`
     - `ADMIN_PASSWORD` = ваш пароль (12+ символов)
     - `CORS_ORIGIN` = `*`
     - `NODE_ENV` = `production`
     - `HOST` = `0.0.0.0`
4. Deploy. Адрес сервиса появится сверху; проверьте `<адрес>/api/health`.
5. Админку можно положить туда же или на Vercel (см. тот же документ).

APK собирается в Codespaces (путь 2, шаг 4) с адресом Render.

## Частая проблема: код на GitHub устарел

Локальные правки (скрипты `scripts/*.sh`, папка `.devcontainer/`, документы) нужно
отправить на GitHub, иначе Codespaces их не увидит. Если `git push` не проходит:

```bash
git push origin main
```

Если пишет `403` или `invalid credentials` — токен только для чтения. Заведите
токен с правом **Contents: Read and write**:

1. GitHub → **Settings → Developer settings → Personal access tokens → Tokens
   (classic)** → **Generate new token**.
2. Отметьте галочку **repo** (или `Contents: Read and write` для fine-grained).
3. Скопируйте токен и используйте в адресе:

```bash
git remote set-url origin https://<ТОКЕН>@github.com/normanrus/Bomba-bet.git
git push origin main
```

После этого Codespaces подхватит настройку автоматически.
